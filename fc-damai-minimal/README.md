# FC Damai Football Academy — نسخة مبسّطة

هاي نسخة مبسّطة من نفس الموقع، بنفس الشكل والتصميم بالضبط، لكن بأقل عدد ملفات ممكن
(21 ملف فقط بدل 98)، عشان تكون أسهل بالفهم والتطوير.

## شو انشال من النسخة الأصلية وليش

- **نظام pnpm monorepo/workspace** — كان معقّد وغير ضروري لموقع بصفحة وحدة، تحول لمشروع
  عادي بـ `npm` واحد بس.
- **إعدادات ومكتبات Replit** (`@replit/vite-plugin-*`, متغيرات `PORT`/`BASE_PATH`
  الإجبارية) — خاصة ببنية تشغيل Replit الداخلية، مش لازمة تشغل الموقع بشكل طبيعي.
- **مكتبة `lib/api-client-react`** — كانت موجودة بس مش مستخدمة أبداً بالموقع (ما فيه API
  حقيقي).
- **مكتبة shadcn/ui كاملة (~50 ملف)** — كان مستخدم منها فعلياً غرفتين (`Toaster` و
  `TooltipProvider`) وما كان لأي منهم أي تأثير مرئي على الموقع (ما فيه توست ولا tooltip
  ظاهر أبداً بالتصميم)، فتم حذفهم بدون أي تغيير على الشكل.
- **صفحة 404** (`not-found.tsx`) — نفس الشكل تماماً، بس بدون الاعتماد على مكون `Card`
  الجاهز (استبدلته بـ `div` عادي بنفس الكلاسات).
- **5 صور غير مستخدمة** من أصل 16 بمجلد الصور — الموقع كان يستورد 11 صورة بس.

## شو انضاف (كان لازم للموقع يشتغل خارج بيئة Replit)

- ملف `index.html` — ما كان موجود بالريبو الأصلي أصلاً (Replit كانت بتولّده تلقائياً من
  عندها)، أي مشروع Vite عادي محتاجه كنقطة دخول.

## كيف تشغله محلياً

```bash
npm install
npm run dev       # للتطوير المحلي
npm run build     # لبناء نسخة الإنتاج بمجلد dist/
```

تم اختبار الـ build والـ typecheck وشغالين بدون أي أخطاء.
